# Next planned scope: v0.042 - Finished boat art

The owner requests a roadmap to make the complete game as good as Starsector.
The installed v0.041 remains a prototype; feature presence is not quality.
This turn prepares the plan only. No new build or native test is authorized
by this planning request.

The next implementation scope is three finished representative boats: starter
skiff, armed escort and large merchant. Establish one coherent scale, lighting,
material and silhouette standard in the actual battle and refit views. Use
an authored model-to-sprite or painted directional-asset pipeline with separate
interchangeable weapon mounts and cheap runtime rendering. Motors, deck
machinery and guns need finished shapes, not another color/subdivision pass.

Done means all three look convincing and readable at normal play zoom, retain
correct physical mount/aim locations and have a repeatable low-cost pipeline.
A concept sheet, close-up or passing script check alone does not finish it.
Produce the remaining33 only after that standard is established.

The proposed0.042-0.061 sequence is in VERSION MAP.txt. Full quality criteria,
playable outcomes and milestone rules are in
[the quality roadmap](docs/roadmap/STARSECTOR%20QUALITY%20ROADMAP.txt).
The first10 versions must prove art, fluid combat, capable AI, useful refitting,
readable navigation and a satisfying first voyage before broader campaign work.

Preserve Windows/Godot, inexpensive water, numerical crew, coins/actual costs,
WASD camera, default autopilot and300-point deployment separate from ownership.
Reuse existing tools. Native tests, when implementation is requested, use the
shared queue and complete selected batches below120seconds; no input/focus takeover.
