BRASS TIDE — FAST DEVELOPMENT TOOLS
20 October 2026 | working scripts in the source repository

These tools run isolated numerical battle fixtures. They do not load a career, mutate a save, play sound, open a foreground game or use the mouse/keyboard. The runner refuses a detected existing Brass Tide or Godot process. All tests are serialized. An owned process has a 20-second timeout; the internal work loop has a 10-second budget.

Run from outputs/brass-tide:
  python tools/qa_brass.py --list
  python tools/qa_brass.py --scenario duel --engine "C:/path/to/Godot_console.exe"
  python tools/qa_brass.py --scenario full_300 --engine "C:/path/to/Godot_console.exe"
  python tools/qa_brass.py --suite smoke --engine "C:/path/to/Godot_console.exe"
  python tools/qa_brass.py --suite all --engine "C:/path/to/Godot_console.exe"

Options: --seed <integer>, --seconds <simulation seconds up to180>, --logs <output directory>.
Presets: duel, all_weapons, mixed, full_300, reserve_boundary, torpedoes, rockets.
Reports include source game version, seed, points, reserves, numerical checks, weapon coverage, projectile/effect peaks and simulation tick timing. A null battle result means the bounded sample ended, not a claimed win. Lab fixtures have explicit free full stores; the economy is intentionally outside this test.

Each launch uses a unique report token and validates the scenario, seed and requested duration, so a leftover report cannot count as a fresh pass.

Territory concept tool:
  python tools/plan_territory.py --out "../Brass Tide - Next build plan"
It creates a planning PNG and coordinate draft from the existing map and confirms the playable world file bytes are unchanged. The placement draft does not prove route safety or save migration.
