# v0.002 combat specialist — raw report

Implemented only the assigned combat allowlist. Deployment is independent and exposes LIMIT=300, cost/total/fits/split. Formula costs use base hull role/tier/HP/size within 8..75; canonical effective deploymentPoints override that formula, retaining oversized values so those boats remain reserves. Splits preserve roster order and original references.

Battle defaults to flagship autopilot. Per-tick manual:true or set_autopilot(false) enables the retained manual controls. issue_order validates an entire selection/target before applying move/attack/escort/hold/engage/withdraw; boat.order and boat.orderTarget hold bounded command state. Targets use {x,y,shipId}; attack without shipId chooses nearest. Fleet-wide set_order and select_flagship remain available. Active deployment is limited independently for each side, with untouched original reserves in st.reserves and deployed point totals in st.deployment. Living reserves neither count as wrecks nor block active-force results.

Optional fitted mounts have independent weaponCooldowns and integral costs against shared finite ammo. Legacy cooldown aliases the primary timer. AI leads moving targets and rotates for fixed arcs; exact segment/shore checks prevent firing through nearby land. Bullet/shell/rocket/torpedo metadata exposes distinct radius, height and trail. Rockets ignite and blast nearby enemies; torpedoes penetrate armor and create waterline breaches. Effective speed/turn/armor and fuelUse remain authoritative. State/RNG remain caller-owned, deterministic and bounded.
