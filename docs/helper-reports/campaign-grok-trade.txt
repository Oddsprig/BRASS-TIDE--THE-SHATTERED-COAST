PUBLIC API
game/scripts/trade_intel.gd extends RefCounted. Static calls only. No class_name.
Book: state.tradeIntel. JSON objects, arrays, strings, bools, and finite numbers only.

ensure(state) -> Dictionary
  Creates or repairs state.tradeIntel. Does not read live prices and does not mint coins.
  Keeps observations, blockade status, and the event log. Caps observations at 16 and events at 40.
  Returns the book.

observe(state, port, day) -> Dictionary
  port is a port dictionary or a port id already in state.ports.
  Copies that port's stock, Economy.price buy quotes, Economy.price sell quotes, and port.cash.
  port.cash is the only business fund stored. Household, expert, and government purses are not copied.
  day is stored as floor(day). A later visit to the same port replaces that one record.
  Does not change stocks, purses, cargo, or port.blockaded.
  Returns ok, seen, portId, day, businessFunds, message.

report(core, port_id) -> Dictionary
  core is the campaign state dictionary, {state, world, nav}, or an object with state/data/nav.
  Unvisited: seen false, uncertainty "unseen", scarcity {}, businessFunds null, no buy or sell keys.
  The message says live remote stock and prices are omitted.
  Visited: stocks, buy, sell, and businessFunds are the stored visit, never the live port.
  age = floor(state.day) - observed day. quote is "observed" on day 0 and "stale" after that.
  uncertainty = min(0.48, age * 0.06). estimate true. guaranteed false. source "visit".
  scarcity is per good: stock, equilibrium, band.
  equilibrium uses Economy.get_equilibrium_stock on the visited industry, specialty, population, and wealth.
  band is scarce below 0.55 of equilibrium, surplus above 1.45, otherwise stocked.
  scarcitySummary is the band of the good with the lowest ratio.

opportunities(core) -> Array
  At most 8 rows, best net per other port, highest net first.
  Empty when travel speed is 0, or when no visited destination can take carried goods or a local buy.
  A destination with no observe() record is skipped. Its live price and stock are not read.
  The port under the player (distance < 65, same test as campaign.current_port) is the counter.
  Local buy quantity is limited by that port's live stock, Economy.price buy quote, coins, free hold, and buyer liquidity.
  Carried quantity is floor(cargo) minus state.freight of that good, then limited by buyer liquidity.
  Buyer liquidity is floor(visited port.cash / visited sell quote).
  Free hold follows expedition.gd: sum of cargo on crewed, unstored, unmothballed boats, minus cargo weight, freight weight, and fuel/supply/ammo above tank capacity.
  One row is chosen per destination: carried or local_buy, whichever has the higher net.
  Fields: ok, estimate, guaranteed, coinsMoved, goodsMoved, mode, good, qty, fromPort, toPort,
  buyQuote, sellQuote, spread, revenue, purchaseCost, wageCost, dailyWages, fuelDrums, fuelCost,
  foodCost, tripCost, netProfit, businessFunds, buyerLiquidity, freeCapacity, days, distance, speed,
  path, quoteAge, uncertainty, risk, riskFlags, message.
  risk is the string ESTIMATE. guaranteed, coinsMoved, and goodsMoved are false.
  netProfit = revenue - purchaseCost - wageCost - fuelCost - foodCost.
  Carried purchaseCost is 0. spread is sellQuote minus buyQuote (0 when the goods are already aboard).
  Nothing in the campaign is moved.

  Cost equations, all labeled estimates:
  - speed = campaign.gd travel_speed. Slowest crewed traveling boat, times max(0.25, Damage.get_status speedFactor)
    when the boat has damage fields, else speedFactor 1. Fuel at 0 multiplies by 0.3.
    Then * 1.55 * world CAMPAIGN_SCALE (default 1) * poweredMass / (poweredMass + towMass * 0.8).
    Mothballed and under-minimum boats are tow mass. Sunk and stored boats are omitted.
  - days = distance / speed / 45 * 2. Out and back only. expedition.gd's extra 2 reserve days are not added.
  - dailyWages = Economy.daily_upkeep(state.fleet).wages, which is round(crew * 100). This matches apply_economy,
    including crew on stored boats. wageCost = ceil(dailyWages * days).
  - fuelDrums uses campaign.gd step while sailing: per boat, (0.011 + size * 0.0002) * max(0.2, fuelUse) * seconds.
    Seconds are the round trip. Idle Economy.daily_upkeep fuel is not added on top.
    fuelCost = ceil(fuelDrums * local Economy.price(fuel, buy)). At sea, with no counter, fuelCost is 0.
  - foodCost = ceil(Economy.daily_upkeep food * days * local food buy quote). At sea, foodCost is 0.
  - Campaign wage and food ticks are whole days. This prorates the sail and rounds the coin cost up.
  riskFlags: blockade, stale, shortFuel, noPath, fuelUnpriced, hostileWaters.
  path is "water" when core.nav has nodes and Navigation.find_path returns a route; otherwise "straight".
  A failed path sets noPath and still uses the straight-line distance.

blockades(core) -> Array
  Port ids, sorted, that are blockaded right now. Read only. Does not write the book or port.blockaded.

update(core) -> Array
  One assessment of current owners. Not a per-frame pass and not a multi-day simulation.
  Root should call it from the economy-day tick, not from campaign.step.
  Returns only the status changes from this call. The book keeps the newest 40, front is newest.
  Stored status keys: kind, portId, active, cause, ownerId, day, hostileForce, oppositionForce.
  Causes that are emitted: established, lost, withdrawn, contested.
  A port that stays clear does not emit. Repeating the same active cause does not emit.
  Does not mint coins, edit stocks, append a port ledger, or set port.blockaded.

BLOCKADE RULE
A story owner whose id starts with "story-" is ignored. Existing story blockade flags are left untouched.
Hostile means faction relation <= Factions.ENEMY_AT (-20). If state.relationships.pairs exists, Factions.relation is used.
Otherwise Factions.PAIR_BASE is used and the book is not created. A faction is not hostile to itself.
The owner must be active and near the port. Near means a same-id patrol within 160 units, or that patrol's
progress is within 0.12 of the end that is this port, or owner.atPort equals the port when the patrol has no x,y.
An inactive patrol does not count. If the patrol has coordinates, a stale atPort does not keep it near.
Supplied means at least one boat that is not sunk, with crew >= max(1, crewMin), fuel >= 0.5, and ammo >= 10.
Force is the sum of max(1, hp/40) over those boats. Establishing requires force >= 2.
Other non-story owners who are not hostile to the port add their supplied near force as opposition.
A player fleet within 160 counts too, excluding sunk, mothballed, and stored boats, but only when
Factions.is_hostile(state, port faction) is false. With no relationship book the player is not treated as hostile.
Opposition greater than or equal to the hostile force contests the port and the blockade is not active.
If a blockade was active and the holder is no longer supplied, the cause is lost.
If the holder is still supplied but no longer near, the cause is withdrawn.

NOT DONE HERE
No automatic coin or goods transfer. No second price table. No invisible ship between ports.
Fleets.dock remains the delivery. A lost convoy changes stock only when that dock sale is lost; this module does not remove the cargo.
Dynamic blockade ids are not written onto port.blockaded. Economy.price therefore does not yet apply the 1.15 blockade bias from this book.
Root can pass blockades(core) as Economy.tick_ports options.blockaded when it wants that bias.
Contraband, inspection, and scripted mission blockades are not migrated.
