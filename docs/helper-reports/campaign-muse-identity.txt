PUBLIC API (game/scripts/fleet_identity.gd, extends RefCounted, all static)
- ensure(state) -> Array: normalizes state["specialists"], monotonic
  state["specialistSeq"], and per-boat conversion (unknown ids cleared),
  specialistActive {}, serviceHistory [] (<=12), service {} counters.
  Specialist record: {id "specialist-N", boatUid, role, name, coins,
  arrears, premiumPerDay, active, hiredDay, portId}. Plain JSON only.
- conversions() -> Dictionary (plus roles() convenience): deep copy of the
  five-entry catalog below.
- quote_conversion(core,uid,id) -> Dictionary: read-only; local
  Economy.price materials + shipwright/mechanic/engineer wages from
  goods.gd WAGES (125/150/200) + 8% yard margin + 5% duty (the refit.gd
  split). Refuses unknown/sunk boat, unknown or already-installed
  conversion, no yard, insufficient physical stock, or insufficient free
  workers (availableWorkers - _yardWorkersUsed) / specialists
  (availableSpecialists - _yardSpecialistsUsed).
- install_conversion(core,uid,id) -> Dictionary: re-quotes, checks captain
  coins before any write, then Money.move splits (materials+margin ->
  port cash, shipwright wages -> householdPurse, mechanic+engineer ->
  expertPurse, duty -> governmentPurse), deducts stocks, reserves yard
  labor in the refit _yard*Used fields, sets boat.conversion and rebuilds
  boat.spec = effective(boat, core.fitted_spec(boat)). Damage, water,
  breaches, stores, crew, loadout and weaponMounts are never touched.
  One interior conversion per boat; installing a different one replaces it
  at full price with no refund (root may add a locker later).
- effective(boat, fitted_spec) -> Dictionary: canonical rebuild. Applies
  the conversion multipliers/added factors and currently-paid specialist
  benefits (boat.specialistActive) onto a copy of the supplied fitted spec
  exactly once; feeding its own output back is a guarded no-op, so stats
  cannot stack. Sets conversion/conversionName and always defines
  surveyFactor/repairFactor/enduranceFactor/upkeepFactor (default 1.0).
- hire_specialist(core,uid,role) -> Dictionary: roles pilot, gunner,
  chief_engineer, surveyor, quartermaster (one of each per boat). Requires
  a docked harbor, a free berth (crew < crewMax), port recruits >= 1,
  workforce >= 1, availableSpecialists >= 1, and coins for the finite
  Economy.recruit_cost(port,1) advance (10 sailor-days, 1000-1200 with
  scarcity). The advance moves captain coins -> aggregate crewPurse
  exactly like Economy.recruit; recruits/workforce/availableWorkers/
  availableSpecialists each fall by one and boat.crew rises by one.
- tick(core, days = 1.0) -> Array of messages: whole days only. For each
  specialist on a living boat, owed = arrears + premiumPerDay x days;
  pays min(captain coins, owed) into that specialist's own coins purse,
  arrears keep the remainder, active = (arrears == 0). Benefit flags on
  the boat follow active, and affected boat.spec values are rebuilt via
  effective(core.fitted_spec). Sunken/missing boats pause premiums and
  preserve the purse (records are never deleted, so coins cannot vanish).
- record_service(core, boat_uids, result) -> void: appends {day,event}
  to each boat's bounded serviceHistory and increments plain counters
  (won/lost/retreated -> battles, won -> wins, rescue/trade/survey ->
  rescues/trades/surveys). Attachment only: no stat, wage or price ever
  reads these counters, so repeat service cannot escalate power.

All goods are existing goods.gd items. No conversion adds, removes or
decorates any weapon or mount; fitted_spec weaponMounts pass through.

SPECIALIST PREMIUMS (per day, on top of the shared 100/day base)
Base wages already flow through Economy.daily_upkeep over boat.crew into
the aggregate crewPurse, and a specialist occupies a berth, so tick() moves
ONLY the professional differential to avoid double pay: pilot 25 and
quartermaster 25 (125-tier wage - 100), gunner 50 (gunsmith 150 - 100),
surveyor 75 (foreman 175 - 100), chief_engineer 100 (engineer 200 - 100).
Paid benefits in effective(): pilot speed x1.03, turn x1.04; gunner base
spec fireRate x1.06 (mount-level fireRate is root's to scale, like morale);
chief_engineer repairFactor +0.25 and pumps x1.10; surveyor surveyFactor
+0.30; quartermaster upkeepFactor 0.95. Numerical crew and default
autopilot are untouched; a gunner/pilot changes numbers, not control mode.

CAVEATS / KNOWN SHORTCOMINGS
- Conversion replacement pays full price with no locker/refund; refit-style
  lockers for interiors are plausible root follow-up work.
- Specialist discharge, death, transfer between boats and name uniqueness
  beyond the rotating authored list are root lifecycle decisions.
- Premiums and benefit magnitudes are first-pass tuning anchored to the
  published trade wages; survey/repair/endurance factors do nothing until
  root applies them in the systems named above.
- tick() pays specialists in record order when coins run short; a fairer
  pro-rata split is possible root policy if playtests want it.
