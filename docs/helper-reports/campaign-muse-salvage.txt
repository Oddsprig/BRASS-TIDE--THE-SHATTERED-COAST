PUBLIC API (game/scripts/salvage.gd, extends RefCounted, all static)
- ensure(state: Dictionary) -> Dictionary
  Creates/normalizes state["wrecks"]: Array (bounded to 128, settled records
  pruned before unclaimed ones) and state["wreckSeq"]: int. Sanitizes every
  record to plain JSON fields, drops duplicate ids, and raises wreckSeq past
  every existing numeric suffix so ids stay monotonic across save/load.
  Wreck record: {id "wreck-N", sourceId, shipId, uid, hull, name, team,
  friendly, x, y (campaign chart position), battleX, battleY (battle-local),
  cause, day, stores {good:qty}, components {good:qty},
  status unclaimed|stripped|towed, claimedMode, towedBoatUid}.
- record_battle(core, battle: Dictionary, source_id: String) -> Array
  Records each actually destroyed boat (battle.ships with sunk == true),
  enemy and friendly, using that ship's own spec, stores and team - never a
  first-enemy spec. Cause is joined from battle.wrecks (combat_events
  record_wreck) by ship id/uid when present. Live/reserve boats are skipped
  and duplicate ships inside one battle are recorded once. Chart x/y is
  state.position at settlement; battle-local coordinates are preserved
  separately. Idempotent per source_id: a repeat call returns copies of the
  existing records and appends nothing. Root should pass a stable source id
  per engagement (for example "battle:<owner/patrol id>:<econDay>").
- seed_site_wreck(core, site: Dictionary, hull_id: String,
    source_id: String = "", stores: Dictionary = {}) -> Dictionary
  Seeds one finite authored wreck at a survey site anchor {id,x,y} for a
  known hull. Components are a fixed 30% of the hull blueprint (no roll);
  stores default empty unless root passes explicit finite amounts.
  Idempotent by source_id (default "site:<site id>"): reseeding returns the
  first record unchanged, even with a different hull argument.
- nearby(state: Dictionary, position, radius: float = 180.0) -> Array
  Unclaimed wrecks within radius of a chart position ({x,y}/Vector2/[x,y]),
  nearest first; copies carry a transient "distance" field.
- quote(core, wreck_id: String, mode) -> Dictionary   (read-only)
  mode "strip": {ok, items {good:qty}, weight, freeCapacity, coins:0,...}.
  mode "tow": {ok, ordinary, expert, fee, total/coins, repairLiability
  {missingHp, supplies}, towSpeedFactor 0.55, hpFraction 0.35, harbor,...}.
  Refuses settled wrecks, unknown wreck/mode/hull, insufficient hold space
  (strip), missing last harbor, roster/points refusal via core.can_add_boat
  + core.points_refusal, or insufficient captain coins (tow).
- recover(core, wreck_id: String, mode) -> Dictionary
  Returns the refused quote and mutates nothing when not ok; every capacity,
  roster, harbor and coin check happens inside quote() first.
  strip: adds the quoted stores+components to state.cargo exactly once,
  zeroes the wreck inventory, sets status stripped. Never moves coins.
  tow: pays ordinary -> lastPort.householdPurse, expert -> expertPurse,
  fee -> cash through money.gd move() with the moneyLog ledger (the proven
  campaign.gd salvage_boat pattern), then core.add_boat(spec, 0) and stamps
  hp = 35% maxHp, crew/fuel/ammo/supplies 0, mothballed true, towed true,
  towSpeedFactor 0.55, salvageWreckId, needsHarborRepair true and
  repairLiability. Sets status towed with towedBoatUid and returns boatUid.
  Choosing tow forfeits the strip inventory (zeroed with the hull transfer),
  so one hull can never be both stripped and towed, nor settled twice.
- find_wreck(state, wreck_id) -> Dictionary  (live record or {})

FORMULAS DERIVED FROM EXISTING SOURCE
- Stores: surviving ship fuel/supplies carry over 1:1 (harbor.gd loads cargo
  fuel/supplies into working stores at the same units). Ammunition rounds
  convert at goods.gd ROUNDS_PER_CASE = 50 rounds per cargo case, kept
  fractional (125 rounds = 2.5 cases) so nothing appears or vanishes.
- Components: construction.gd blueprint(spec).materials for that physical
  hull (timber, logs, iron, copper, supplies, engines, guns, fuel) scaled by
  one deterministic fraction frozen at record time:
  clamp(0.25 + 0.25 * engine - 0.10 if burning, 0.10, 0.50).
  engines/guns floor to whole assemblies. Site wrecks use a fixed 0.30.
- Tow labor: identical to campaign.gd salvage_quote so v0.010 matches the
  shipped price: ordinary = ceil(size/14 * 3 * 100) at the 100 coins
  sailor-day wage, expert = goods.gd WAGES.engineer = 200 for one engineer
  day, fee = ceil(10% of labor). All three are transfers to existing harbor
  purses; Money.total is conserved and the test asserts it purse by purse.
- Repair liability: missing 65% of maxHp at damage.gd hullSupplyPerHp
  (0.35 supply kits per hp). It is an advisory finite estimate stamped on
  the boat; this module charges nothing for repairs.
- Capacity: core.capacity() - core.cargo_weight(); lot weights from
  goods.gd ITEMS. Strip is all-or-nothing against that free space.

CAVEATS / KNOWN SHORTCOMINGS
- Battle ships that were removed from battle.ships before settlement would
  be missed; current battle.gd keeps sunk ships in st.ships, and wreck
  records without a matching ship are used only for cause, not inventory.
- All wrecks from one battle share the single campaign position; per-wreck
  chart scatter is root presentation work if ever wanted (battleX/Y kept).
- Recoverable-fraction and tow-speed constants are first-pass tuning in one
  place; the labor fee formula deliberately matches shipped salvage_boat.
- core is used dynamically (state, hull, port, capacity, cargo_weight,
  can_add_boat, points_refusal, add_boat); a core missing those methods gets
  refusals or empty results rather than partial mutations, except add_boat
  which tow requires after quote() has already verified can_add_boat.
