    - `core.apply_economy(ports, messages, days)` ([`campaign.gd:275-313`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/campaign.gd#L275-L313)) — pays daily upkeep and resets yard daily reservations via [`Construction.begin_day(p)`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/construction.gd#L611-L626).

- **Restocking Repair Kits (`supplies`), Ammunition (`ammo`), and Fuel (`Campaign` + `Harbor` + `Damage`)**
  - **Direct boat resupply from current harbor**:
    - [`core.resupply_boat(uid, "full")`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/campaign.gd#L489-L490) -> [`Harbor.resupply(core, uid, "full")`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/harbor.gd#L188-L211): fills boat up to `ammo = ammoCapacity` (`80 * mount_count`, converted at `50` rounds/case), `supplies = 20.0` kits, `fuel = 60.0` drums from `p.stocks`.
    - Calling `core.resupply_boat(uid, "full")` **before** `core.repair_boat(uid)` loads up to `20.0` kits onto `boat.supplies`, which [`Harbor.service_quote()`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/harbor.gd#L150-L151) uses via `own = minf(boat.supplies, material)`.
  - **Buying reserve `supplies` / `ammo` / `fuel` into fleet cargo at surplus ports & distributing to boats**:
    - [`core.trade(port_id, good, qty, "buy")`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/campaign.gd#L358-L362) -> [`Economy.transact()`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/economy.gd#L477-L533): buys integer cases/kits (`"supplies"`, `"ammo"`, `"fuel"`, `"food"`) into `core.state.cargo[good]` up to `core.capacity() - core.cargo_weight()`.
    - [`core.use_reserves()`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/campaign.gd#L492-L493) -> [`Harbor.use_reserves(core)`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/harbor.gd#L213-L222): transfers `core.state.cargo["ammo"|"fuel"|"supplies"]` directly into each living boat's onboard stores (`ammo` up to `ammoCapacity` at `50` rounds/case, `fuel` up to `60.0`, `supplies` up to `20.0`) anywhere (at sea or in port). Calling `core.use_reserves()` before `core.repair_boat(uid)` lets boats use cargo-carried repair kits (`own`) even when the current harbor's `p.stocks.supplies` is low.
  - **Onboard crew self-repair while sailing or waiting**:
    - [`Damage.set_policy(boat, "repair")`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/damage.gd#L47-L50): when `boat.policy == "repair"` and `boat.supplies > 0`, [`Damage.tick_ship()`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/damage.gd#L135-L146) (called every `core.step(dt)` at [`campaign.gd:231`](file:///C:/Users/bligh/Documents/Codex/2026-10-20/how/outputs/brass-tide/game/scripts/campaign.gd#L231)) patches breaches and restores hull HP (`0.35` supplies/HP) using the boat's own crew and onboard `supplies`.
