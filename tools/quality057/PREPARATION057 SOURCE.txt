Expedition.preview(c, site_id: String, return_port_id: String = "",
    detour_site_id: String = "", target_level: int = 3) -> Dictionary
is the implemented detached read-only seam for C and the existing panels.

Explicit return_port_id is preferred for a paid job sponsor. Empty chooses the
nearest by straight distance accessible harbor with an actual water route from
the selected site. Explicit sponsors are never silently replaced on refusal.

provisions, sails, advances work or changes persistent state.

and return legs, remaining quoted shore work and two contingency days. Adds:
siteId/siteName, returnPortId/returnPortName, routeOk/routeMessage,
travelDays/shoreDays/chartDays/surveyDays, shoreFood/shoreKits,
crewNeeded/spareCrew/crewShortfall, kitShortfall, work (quoted remaining rows),
returnNow (same accounting for immediate return) and detour (empty unless a
known explicit detour is supplied, otherwise same accounting plus extraDays).
readyForAllowance includes actual route, shore crew, kits, food, boat fuel,
hold and total payroll. foodRequired includes shore prepaid food once; fuel
only budgets sailing plus sailing contingency, never idle shore work.
