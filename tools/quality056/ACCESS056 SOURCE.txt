API SEAM (published before implementation; now implemented in this checkout)
Politics.access(c, port: Dictionary) -> Dictionary retains existing permissions
and keys. Adds safeConductActive:bool, safeConductUntil:float (absolute campaign
day; zero when absent), safeConductDays:float (remaining, zero when expired),
standingReason:String. reason explains effective entry and the recorded expiry;
an active pass replaces the base refusal wording, not the standing or offenses.
Existing civilian-pass overrides only: inspected/legal/inspection/contracts.
Claims, military fittings, restricted bulk goods and actual customs remain.

Politics.encounter(state: Dictionary, owner: Dictionary) -> Dictionary is a
detached, read-only public projection: kind:String, role:String,
factionId:String, factionName:String, hostile:bool, reason:String.
Uses actual owner kind/faction and Factions.standing only; no live orders,
positions, cargo quantities, purses, targets or observation changes. Main uses
this only inside show_patrol_encounter, preserving local hail boundaries and
the existing local purpose line, choices, battle policies and QA captures.
This query does not authorize hailing or reveal a remote contact.
