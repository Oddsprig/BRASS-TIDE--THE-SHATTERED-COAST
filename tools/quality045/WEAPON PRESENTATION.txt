Production change
BoatSpriteArt.draw_weapon no longer depends on ctx.authored_hull. The existing
seven authored variants now serve every valid isometric fitting across all36
boats, including the normal BoatPortrait/workshop composition. The three
authored hulls and33 procedural hulls retain their existing hull paths.
No assets or bake sources changed; no new bake is requested.

Single/twin machine gun, cannon, three/six-cell rocket and single/twin torpedo
selection still uses the actual kind, fitting tier and moduleId. Every position
uses the existing normalized mount x/y, stable mount ID and localAimAngles.
Sizes, muzzle stations and firing heights still come from WeaponGeometry.
MountLayout/Refit still own firing arcs, including044's135degree heavy forward
cannon socket and the fixed launchers'0.9radian arc. Rendering does not invent
aim, rounds, projectiles, timestamps, condition or firing capacity.

WeaponArt.recoil_offset(ctx,mount) is the only new public callable. It returns
canonical model X displacement from that mount's shots[id] and shot_clock:
-1.1units immediately after discharge, recovering linearly over0.16seconds.
RECOIL_SECONDS and RECOIL_DISTANCE name the existing values. Authored moving
assemblies and mechanical fallback share this calculation; only gun/cannon
mechanisms use it. A missing/future/expired timestamp produces zero displacement.
The display clock alone cannot drive recoil. BoatArt still suppresses saved
shot timestamps outside combat and still overlays real disabled/damaged marks.
No game/save/data schema, worker, economy or simulation API changed.

Both weapon cells must be loaded and fully inside their actual PNG before
either layer is submitted. Missing base/moving atlases and invalid regions
therefore return to the existing mechanical art without partial sprite layers.
Nonisometric projection, texture-incapable recorders and legacy enlargement
also retain mechanical rendering. Legacy enlargement scales XY but leaves
height alone; an isometric bitmap cannot represent it faithfully.
