2. CANONICAL INSTANCE API (OceanChart064)
All methods consume OceanWorld064.view(...).view payload `V` directly (never the outer `R0` wrapper) and never read `chart.host` or `core.state`.
Missing/invalid input, outer `R0` wrapper, bool coordinates, unknown layer/regionId pairs, or non-north/south approaches fail cleanly (`{}` / `Rect2()` / `ok:false`). No field aliases, synthetic fallback geography, or optional contacts are accepted.
All `chart` parameters are untyped (`Variant`) so custom `Chart` script members (`project`, `world_line`, `world_ring`, `campaign_overview`, `_projector`, `_draw_chart_labels`, `text_at`, `draw_compass`, `scale_factor`, `zoom`) compile cleanly under Godot 4 GDScript static typing.

- draw(chart, view: Dictionary) -> Dictionary
  Validates full `V` schema (`layer`, `regionId`, `name`, `bounds`, `position`, `heading`, `path`, `destination`, `islands`, `regions`, `approaches`, `boats`, `homeInteractions`).
  - `layer == "home"` (`regionId == "shatter_coast"`, `homeInteractions == true`):
    Performs no drawing and returns empty metrics with `ok: true` and `delegate_home: true`. B's `Chart` keeps the original home campaign drawing unchanged and may call `draw_approaches(self, v, labels)` before `_draw_chart_labels(labels)`.
  - `layer == "local"` (`regionId == "glasswind_keys"`, `homeInteractions == false`):
    Prepares/reads cached `CoastArt050` island meshes via `prepare_local_region(V)`, draws graticule over `V.bounds` (`4200x3000`), draws the 3 Glasswind Keys islands via `NauticalArt.draw()`/`CoastArt050.draw()`, draws north/south coastal approaches from `V.approaches`, draws active course `V.path`, positions and draws the player flotilla from `V.boats` at `chart.project(V.position)` / `V.heading` via `FleetArt054.layout(V.boats, marker, float(V.heading), scale_factor, {"viewport": viewport_rect, "overview": zoom < 0.7})` + `FleetArt054.draw()` (ignoring any stale battle `boat.x`/`boat.y`), and draws collision-avoided labels (`chart._draw_chart_labels()`), scale bar, and compass.
  - `layer == "ocean"` (`regionId == "open_ocean"`, `homeInteractions == false`, `V.islands` empty, `V.regions.size() == 2`):
    Prepares/reads cached `CoastArt050` ocean-footprint meshes from `RV.silhouettes` (`Array[Array[P]]`), draws ocean graticule over `V.bounds` (`4800x2800`), draws both regional groups (`shatter_coast` and `glasswind_keys`), draws north/south ocean approach gates from `RV.approaches`/`V.approaches`, draws active course `V.path`, positions and draws the player flotilla from `V.boats` at `chart.project(V.position)` / `V.heading` via `FleetArt054.layout` + `FleetArt054.draw()`, and draws collision-avoided labels, scale bar, and compass.
  Returns metrics Dictionary:
  `{"ok":bool, "delegate_home":bool, "layer":String, "regionId":String, "regions_drawn":int, "islands_drawn":int, "vessels_drawn":int, "textured_vessels":int, "approaches_drawn":int, "coast_draw_calls":int}`.

- pick_region(view: Dictionary, world_position: Vector2) -> Dictionary
  Consumes `V` and `chart.world_at(screen_pos)`.
  - On `layer == "local"` or `layer == "home"`:
    Tests north/south `AV` entries in `V.approaches` matching `V.regionId` using `world_position.distance_to(P) <= float(av.radius)` (`80.0`).
    Returns `{"regionId":String, "approachId":String, "kind":"approach"}` on hit, or `{}` on miss.
  - On `layer == "ocean"`:
    1. Tests north/south `AV` entries in `RV.approaches` / `V.approaches` first (`world_position.distance_to(P) <= float(av.radius)`, `8.0` ocean units). Returns `{"regionId":String, "approachId":String, "kind":"approach"}`.
    2. Tests `RV.silhouettes` polygons via `Geometry2D.is_point_in_polygon(world_position, poly)`. Returns `{"regionId":String, "approachId":"", "kind":"region"}`.
    3. Returns `{}` on open-water miss.

- prepare_local_region(view: Dictionary) -> Dictionary
  Consumes `V` for `local/glasswind_keys` only (rejects `home` and `ocean` layers, empty `V.islands`, or `HOME_ISLAND_IDS`).
  Builds and caches `CoastArt050.prepare_island(...)` plans under a deterministic key `layer:regionId:bounds:island_fingerprint` (bounded to 8 entries on the `OceanChart064` instance; never mutates `chart._chart_sheet` or `chart._chart_towns`).
  Returns `{"cacheKey":String, "layer":String, "regionId":String, "name":String, "bounds":Rect2, "sheets":Array}` or `{}` on invalid input.

- world_bounds(view: Dictionary) -> Rect2
  Validates `(V.layer, V.regionId)` and `V.bounds = {x, y, width, height}` (`width > 0`, `height > 0`) and returns `Rect2(x, y, width, height)`, or `Rect2()` on invalid input.

- Additional helpers for B (`chart.gd` integration):
  - `draw_approaches(chart, view: Dictionary, labels: Array = []) -> int`: draws north/south approach gates from `V` and appends gate label entries to `labels` so `Chart.draw_campaign()` can call it after original home painting before `_draw_chart_labels(labels)`.
  - `content_bounds(view: Dictionary) -> Rect2`: tight bounding box of active layer's silhouettes/islands + approaches (falls back to `world_bounds(view)`) for `Chart.territory_view()`.
