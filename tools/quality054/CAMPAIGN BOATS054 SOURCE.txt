static func layout(boats: Array, center: Vector2, heading: float,
    zoom: float = 1.0, opts: Dictionary = {}) -> Dictionary
  boats: actual active/visible boat dictionaries, in desired lead-first order.
  center: chart screen point. heading: screen radians, +X is bow; chart's
  top-down world heading can pass through unchanged. zoom: chart scale_factor.
  Input arrays/dictionaries remain untouched. At most five actual hulls drawn.
  No fabricated escorts. Empty input yields empty vessels and empty bounds.
  ORDINARY SCALE0.30 IS NOT OVERVIEW. Root now explicitly requires the starter
  roughly60-80px at ordinary0.3. Overview requires scale<=0.22. An old caller
  passing overview=true at0.3 cannot shrink ordinary boats. overview=false
  can retain ordinary art at lower scale. The chart's broader label/coast
  overview threshold may remain its own policy; boat art owns this size floor.
  Ordinary tin_skiff is about68px including drives; large merchants about120px.
  Overview starter about28-32px. Title size_multiplier1.3 is supported.
  opts: viewport:Rect2 (optional culling), size_multiplier:float (default 1),
    max_vessels:int (default 5, clamped 1..5), overview:bool (optional override).
  Return: vessels:Array[Dictionary], bounds:Rect2, hit_radius:float,
    roster_count:int, visible_count:int, omitted_count:int, culled_count:int,
    lod:int (0 close/1 ordinary/2 overview). Counts exclude sunk, hidden,
    visible=false, mothballed or storedPort boats and unresolved hull IDs.
  Each vessel: uid:String, hull_id:String, center:Vector2, angle:float,
    length_px:float, beam_px:float, bounds:Rect2, transform:Transform2D,
    asset_path:String, mounts:Array, motors:Array. transform maps normalized
    hull-local XY (bow +X; multiply canonical stations directly) into screen.
    mounts preserve effective-spec physical x/y, id/kind/size/angle; local_x/y
    are x/y divided by hull size and are used with transform. No fitted guns
    are baked into the hull; an explicitly empty weaponMounts yields no guns.
