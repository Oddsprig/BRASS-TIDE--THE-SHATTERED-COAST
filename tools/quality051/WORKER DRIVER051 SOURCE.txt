EARLY API FOR MAIN/CHART/INTERFACE AND PROOF OWNERS
const Driver051=preload("res://scripts/battle_driver051.gd")
var driver=Driver051.new(initial_battle) # transfers a detached state; no engine work
battle=driver.advance(0.0,{},true) # initial Main-owned display dictionary
battle=driver.advance(delta,input,paused) # call EVERY render frame, even paused
driver.queue_command(kind,payload) -> bool # accepted to FIFO, worker validates
driver.take_events() -> Array # drains published audio/feedback exactly once
battle=driver.retire() # explicit join + tactical child drain, canonical final data
driver.telemetry() -> Dictionary # published counters + Main polling/lag
driver.presentation_fraction() -> float # interpolation fraction [0,1]
driver.presentation_poses() -> Dictionary # {previous:{id:pose},current:{id:pose}}
  pose={x,y,angle,turretAngle}; only render uses lerp/lerp_angle, never physics.

advance never joins an unfinished ordinary task. Fixed 1/30 steps, at most four
per job to catch up after a slow rendering frame; normally one per due job.
outstanding real-time debt is retained/reported, never silently discarded.
Pause blocks new physics (an already submitted bounded job can complete). Commands are
FIFO at the next owned boundary; paused command-only jobs do not tick physics.
retire is idempotent and joins only this driver and its detached tactical jobs.
Retire BEFORE campaign settlement and before replacing/clearing an encounter.
Driver retains original ship dictionaries on Main only. retire reconciles the
joined final ships/reserves/escaped ships into those original owners in place
before returning canonical data; call it BEFORE campaign settlement. No caller
fleet reconciliation is required. Worker never receives these originals.
Ship owners match stable UID (battle ID fallback for anonymous lab actors).
Reserve owners retain side/index identity. Captured and escaped arrays plus
convoy.actors are explicitly relinked to this state's ships; Variant deep copy
does not preserve those aliases across containers. Retire also restores coastal
battery port records in place so campaign ammunition/stores remain conserved.
The final retired result reconstructs a fresh Main-owned RNG from the joined
seed/state: Boarding.settle/_setup requires it even when no prizes are present.
Active display snapshots contain no RNG; no worker RNG object is published.

Battle proxies on a mirror queue instead of mutating authoritative state:
select_flagship, set_autopilot, issue_order, set_order, set_tactical_options,
retreat, NEW set_crew_policy(st,ids,policy), set_repair_priority(st,ids,priority).
Queue kinds/payloads: flagship {id}; autopilot {enabled}; order {ids,order,target};
fleet_order {order,target}; options {ids,options}; retreat {};
crew_policy {ids,policy}; repair_priority {ids,priority}.
