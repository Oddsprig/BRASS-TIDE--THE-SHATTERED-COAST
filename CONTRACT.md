# Brass Tide v1 module contract

Dependency-free browser game, Canvas 2D. Original motorboat world. JS modules use IIFE and expose globalThis.BrassSystems / BrassEconomy / BrassData, plus module.exports in Node. No imports, packages, DOM or network in these modules. Desktop double-click must work with classic script tags. Fixed-step battle simulation, flat water, no fluid rendering.

## Damage module systems.js
API createShip(spec, overrides={}) -> mutable plain ship; spec has id,name,hp,armor,speed,turn,crewMin,crewOptimal,crewMax,cargo,price,weapon,fireRate,damage,range,size,pumps. Ship has id,type (spec.id),name,maxHp,hp,armor,crew,crewMin,crewOptimal,crewMax,wounded,water (0..capacity),capacity,breaches (array of {area,section}),fire (0..100),engine (0..1),supplies,ammo,fuel,sunk,policy ('balanced','bail','repair','fight'), x,y,angle,vx,vy, cooldown. createShip stores spec copy as ship.spec. All operations are deterministic except supplied rng function.
applyHit(ship, hit, rng=Math.random) -> events; hit {damage,kind:'bullet'|'shell'|'torpedo'|'ram',section?:'bow'|'engine'|'stern',penetration?:number}. Damage, probabilistic hole/engine/fire/casualties. tickShip(ship,dt,options={inCombat:true}) -> telemetry {inflow,bailing,repair,crewGuns,crewBail,crewRepair,speedFactor,weaponFactor,events}. dt in seconds. getStatus(ship) same telemetry without mutating; setPolicy(ship,policy); repairAtPort(ship,budget) mutates, returns {cost,repaired,error?}; budget in credits. repair costs account wounds, hull, supplies, and breaches, cannot be free or exceed budget. Sinking if hp<=0 or water>=capacity. Numeric flooding should be playable: light breaches can be bailed, heavy torpedo holes overwhelm a skiff without repairs. Repair patches holes consuming supplies; bail never consumes supplies. Never negative stocks/crew or overallocated crew. auto recovery limited to port or explicit supply/crew. Live hp hull damage persists. Export constants plus pure functions. Test important mechanics with Node built-in assert.

## Economy module economy.js
API createPort(def) -> mutable port storing def properties; def {id,name,faction,x,y,population,industry:'fishery'|'timber'|'foundry'|'refinery'|'shipyard'|'agriculture'|'trade',specialty?,description,wealth}. port has stocks {food,timber,steel,fuel,supplies,ammo,engines}, cash,workers,prosperity (0..100), recruits,shipStock object.
GOODS object for exactly those 7 keys: {name,base,weight,color,unit}. price(port,good,side='buy') credits per unit; buy>sell spread, scarcity affects prices. tickPorts(ports,days,{blockaded:[],rng}) mutates economy, returns short readable event array; industry/labor/input production, population consumption, finite stock, trade transfers, recovery. transact(port,wallet,good,qty,side,capacity) -> {ok,qty,total,message}; wallet {credits,cargo:{...}} with finite hold capacity across goods using weight. side='buy' player buys; side='sell' player sells; transactional, finite nonnegative state, side/qty validation, costs rounded integer. capacity numeric total hold weight. recruit(port,wallet,count,room) -> {ok,count,cost,message}; wallet.crew count optional; charges credits & reduces recruit pool; MUST respect room. dailyUpkeep(fleet) -> {wages,food,fuel}; numbers; ONLY returns amounts, no mutation. export testable pure functions. No dependency on content or systems. Include production/labor telemetry port.lastProduction, port.shortages.

## Content module content.js
API export object {TITLE,VERSION,FACTIONS (array),HULLS(array),PORTS(array),ISLANDS(array),ROUTES(array),MISSIONS(array),START}. Faction {id,name,color,description,doctrine}; 4 original factions with id 'compact','forge','reed','raiders'. HULLS total 24 original buyable boats, plus 2 civilian optional. Hull {id,name,faction,role,hp,armor,speed,turn,crewMin,crewOptimal,crewMax,cargo,price,weapon:'gun'|'cannon'|'torpedo'|'rocket',fireRate (shots/sec),damage,range,size,pumps,tier (1..4),description}. speed 55..150 world units/sec, turn 1..3 radians/sec, hp 100..700, armor0..20, damage8..50, range260..620, price600..24000, optimalCrew3..36, size12..36. Ship spec IDs all unique and available for progression. START {hull:<cheapest ID>,credits:1800,port:<port ID>,supplies:20,food:30,fuel:60,ammo:80,crew:5}. Starting cheap skiff suitable for first pirate fight. PORTS 9 or 10 original ports with world coordinates within x180..2420,y180..1620, each on navigable water near island shoreline. ISLANDS polygon arrays {id,name,color?,points:[[x,y],...]}, leave ports on water, total world 2600x1800. ROUTES array of [portId,portId], all ports connected, mostly water routes. Prefer archipelago islands, water lanes between. MISSIONS 8 sequential main arc contracts {id,title,description,kind:'battle'|'delivery'|'bounty',port:<source>,targetPort:<destination>,enemyHulls:[IDs],reward,renown,cargo?:{good,qty}} escalating 1 weak skiff to flagship boss. Original story about restoring coastal routes under blockade; completion after last mission. All main battles must be winnable with earned fleet. Design coherent progression and produce concise world notes.
