# Brass Tide - quality roadmap prepared

Latest user request is planning: make the whole experience as good as
Starsector. The previous feature-checklist approach did not meet that bar.

Installed/delivered game remains v0.041, tested source
`ee0225bbf39273a0bffd91c27e27589622ca0657`; its release notes/tag, binary,
launcher, voyage and backup are unchanged by this planning task.

New plan: proposed0.042-0.061, three quality milestones. Start with three
finished representative boats and a proper asset pipeline; prove rendered
performance, combat feel, AI, command/refit, whole-roster art and the first
voyage before campaign breadth. Existing systems are prototype foundations.
No fixed version number or assertion count certifies Starsector-level quality.
